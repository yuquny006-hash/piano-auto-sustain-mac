# Mac 授权候选版验收（交给编译朋友）

目前为候选版，不能凭“编译成功”发客户。请填写 Mac 型号/CPU、macOS、Xcode、宿主版本及每项结果。

1. 服务器管理员部署签名服务后，仅把64位十六进制公钥放到工程根目录 mac-public-key.txt。绝不接收生产私钥。运行 `bash scripts/build-mac-licensed.sh`，保留终端日志。
2. 确认 VST3/AU 均含 arm64 与 x86_64，codesign 校验和 ctest 通过；包名必须为 Licensed-CANDIDATE。
3. 完全退出宿主后安装；运行 `auval -v aumi Pam1 Amup`，将完整日志保存。测试 Apple Silicon 原生、Rosetta 或实际 Intel 机器；无法验证的环境写“未测”，不要写“兼容”。
4. Logic 在 MIDI FX 槽加载；Cubase/REAPER 扫描 VST3。重复开关界面、保存关闭再打开工程，核对统一界面、参数、说明书与联系方式位置。
5. 未激活时音符及输入原有 CC64 原样通过，自动踏板不工作、不静音。不得使用客户现有授权码做测试。
6. 专用测试码首次激活成功；AU/VST3共享；断网并重开宿主仍有效；错码/停用码/别机绑定码明确失败。
7. 备份并篡改本地 license.dat 后重开实例必须未激活；恢复原文件后有效。复制测试凭据到另一 Mac 必须无效。使用测试码人工解绑验证新机重绑；旧离线授权不会远程立即作废。
8. 激活期间关闭编辑器、删除轨道、退出宿主不崩溃；断网/慢网取消不长时间卡死。20个实例并用，确认音频无新增爆音。重新激活失败不能覆盖已有有效凭据。
9. 实时演奏、播放、录音都正确出声和延音。Logic设置 Record MIDI to Track Here 后新录片段必须含CC64；旁路插件重放仍有延音。VST3两轨只在钢琴轨留下一份录音。
10. 正常安装、重复安装、升级、卸载保留授权；人为损坏包中的一个文件，安装须在替换前拒绝；模拟第二格式无法安装，第一格式须回滚，旧包保留。系统首次解压隔离状态下实测启动路径。

以上通过后，把测试记录、日志、候选 ZIP 与 SHA256 返回。开发者审核后再生成正式客户包。不要仅去掉 CANDIDATE 字样就分发。
